# Contributing

Two things to know.

## Issues are welcome

Bugs, questions, suggestions, design discussions: open an issue. I read them.

If you've spotted something missing, surprising, or wrong, an issue is the fastest way to reach me.

## Pull requests are not currently accepted

Edict is a single-author portfolio project. The framework is deliberately opinionated, and preserving design coherence matters more right now than crowd-sourcing change.

If you've identified something you think Edict should change, open an issue. If we land on "yes, that should happen," I'll do the work.

This stance may relax later; for now this is honest.
